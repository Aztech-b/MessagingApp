# Simple Messaging App

Simple messaging app as a homework from Odin Project.
!!! The app is not finished yet.

## Frameworks used

- Frontend:
    - React
    - React Router
    - Mantine Components
    - Lucide for icons
- Backend
    - Node.js
    - Express.js
    - Passport for auth with sessions
    - Socket.io
    - Prisma ORM
